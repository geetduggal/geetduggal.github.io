This weekend I created an in-app voice agent in Order.

It is meant to solve issues I have had with GPT and Claude hands free mode:

  • Inability to access local files on my phone much like Claude Code / Codex will on a desktop
  • Inability to properly do deeper research and search the web in voice mode
  • Ability to swap between models and local voices
  • Easily work within the context of a Notable Folder

IMHO this goes beyond just adding a voice/chat harness to the app. More on that in a Medium post coming soon!
